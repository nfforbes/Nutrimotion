# Nutrimotion

A Next.js website with a template-driven design featuring a black header with orange menu items and an orange page background.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Template-based Layout**: All pages use a consistent header template
- **Header**: Black background with menu items in #ee4d24 color
- **Navigation**: Home, Training, and Meals pages
- **Cart & Login**: Top-right corner buttons
- **Responsive Design**: Mobile-friendly layout

## Pages

- `/` - Home page
- `/training` - Training page
- `/meals` - Meals page

## Tech Stack

- Next.js 15
- React 18
- TypeScript
- CSS Modules
